# Kilobat Homebrew tap

Install the network diagnostics CLI and MCP server on macOS 14 or newer:

```sh
brew install seifip/kilobat/kilobat
```

The CLI builds from source and requires Xcode 16 or newer.

Install the Mac app, signed and notarized, with its menu-bar monitor, Wi-Fi diagnostics and data budgets:

```sh
brew install --cask seifip/kilobat/kilobat
```

The app updates itself. More at https://kilobat.app.
